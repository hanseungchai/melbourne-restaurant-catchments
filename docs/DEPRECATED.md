# Deprecated code

Code removed during the cleanup. Nothing here is lost: every line of the pre-cleanup code is
preserved at git tag `legacy-final` (commit `b11551a`).

To view a removed file or function:

```
git show legacy-final:<path>              # e.g. git show legacy-final:hex_search.py
git log -S "<function name>" --oneline    # find the commit that removed a function
```

Data produced by deprecated API code is kept in `frozen_inputs/`; its README names the
producing function at `legacy-final`.
